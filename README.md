# Rec Room CustomEmote Mod

All made by AI slop may be a bit buggy

## How to build

The 2 plugins can be built this way  
You need .net 6  
Bepinex files put in the Bepinex folder you will see it  
Open terminal

1. Run dotnet restore  
2. Run dotnet build  
3. Dll is in bin/Debug/net(X).0/(ModName).dll  
4. Put in Rec Room’s Bepinex/plugins folder

## CustomEmote

The plugin for playing emotes (press F9)  
Too lazy to make keybind configurable  
Config is in BepInEx/config/CustomEmote.cfg

## PoseRecorder

Records your movements to CustomEmote.cfg.  
Works best in VR.  
Default keybind is LeftControl+LeftAlt+LeftWindows+Alpha5 and is configurable  
Config is in BepInEx/config/PoseRecorder.cfg

## EmoteMaker

Edit emotes on a PC with this HTML5 editor.

## Config

Config files are generated when you start Rec Room, it is in Bepinex/config.
