# CustomEmote

## How to build

You need .net 6  
Bepinex files put in the Bepinex folder you will see it  
Open terminal

1. Run dotnet restore  
2. Run dotnet build  
3. Dll is in bin/Debug/net6.0/CustomEmote.dll  
4. Put in Rec Room’s Bepinex/plugins folder

## Config

Config file is generated when you start Rec Room, it is in Bepinex/config.  
PoseRecorder also modifies this config  
You can import this config into EmoteMaker to edit it
